Order and grouping

  • Groups: Needs attention (needsAttention) → Running (incl. starting, resuming) → Paused (incl. pausing, stopping) → Stopped. Archived only under its own filter.
  • Inside a group: newest updatedAt first. Same name: newest createdAt first.
  • Stopped is collapsed behind “Show N stopped bots”. Typing a search opens every state except Archived.
  • PAPER bots keep the PAPER chip on the row.
  • /agent with no id opens the first row of the first group, as today.

Keyboard and screen reader

  • Trigger is a button with aria-haspopup and aria-expanded. Enter or Space opens; focus goes to the search box.
  • Search is a combobox over a listbox; groups are role="group" with a label (“Running, 10 bots”). ↑ ↓ move aria-activedescendant, Home / End jump, Enter opens the bot, Esc closes and returns focus to the trigger.
  • Option name read as: “BTC Market Making, id ending 3f0a9d21, BTC-USD, version 4, Running, net PnL up 18.42 USDC”.
  • The bot you are viewing has aria-selected="true" plus the visible “Viewing” tick, so it is never shown by colour alone.
  • Result count is announced in a polite live region (“3 bots match”).
  • Phone: the same list in a BottomSheet dialog; focus is trapped, the close button is 44 px.
