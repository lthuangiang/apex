# v2.18.1 (2026-11-23)

Danh sách tính từ tag `v2.18.0` (2026-11-23, `main` f5b2e51) tới #491, cộng PR docs này. Tag `v2.18.1` đặt trên commit của PR docs này. Hai thay đổi đều chỉ cho khu team (không đổi gì với người dùng thường); người dùng chọn số `v2.18.1`.

## Cho người dùng (English, dùng được cho GitHub Release)

Team tools only; nothing changes for regular users.

- Market hours: the Market field is now the searchable picker from the bot form (Popular first, then A–Z), and the two CPM rows end with an average for the period.
- Signal Research: the team can export the period's data as one JSON file (24h, 7d or 30d).

Not financial advice. Past results are not a forecast.

## Kỹ thuật

- Market hours (#486 qua #487): ô Market dùng `Picker` + `marketItems` của form tạo bot, chỉ gồm market mà api của trang trả về. Thêm cột Avg cuối hai hàng CPM:
  - "Markout cost / $1M" ("Period avg") = Σ(cost / $1M × volume) ÷ Σ volume, giờ Thin sample vẫn tính;
  - "Est. CPM (estimate)" ("Mean of hours") = trung bình cộng các giờ có số;
  - thiếu dữ liệu hiện "Not available".
- Signal Research Export data (#489 qua #491): `GET /api/v1/admin/signal-research/export?period=24h|7d|30d`, chỉ role team (tester có cờ nhận 403), chỉ đọc, trả file JSON theo `srExportSchema` (`packages/shared`).
  - Tám khoá: `meta`, `articles`, `context`, `versions`, `paperTrades`, `mainnet`, `costs`, `sources`.
  - `mainnet` chỉ số gộp (DEC-361). Không xuất email, user id, địa chỉ ví, id bot, nội dung / URL bài, lỗi thô của nguồn.
  - Mỗi phần tối đa 5.000 dòng; vượt trần ghi `truncated` / `total` / `omitted` trong `meta`.
- Việc còn mở: #488 (a11y nút giờ có mốc trên Market hours, có từ trước).
