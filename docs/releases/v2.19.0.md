# v2.19.0 (2026-11-26)

Danh sách tính từ tag `v2.18.8` (2026-11-25, `main` 9dae1a5) tới #552 (`main` 4ee15e0), cộng PR docs này. Tag `v2.19.0` đặt trên commit của PR docs này. Chủ sản phẩm gõ "release" ngày 2026-11-26 để thử trang chẩn đoán SoDEX rewards bằng ví thật. **Prod đang ở v2.18.7 (v2.18.8 đã gắn tag nhưng chưa deploy), nên lần deploy này mang theo cả v2.18.8: hai migration (`0061`, `0062`) và mặc định "Where to quote" = 2 cho bot Market Making mới (`docs/releases/v2.18.8.md`).**

## Cho người dùng (English, dùng được cho GitHub Release)

- Signal Research: when one news article names several coins for the same event, each coin now gets its own signal and the order size is split between them. A repost of the same event within 24 hours no longer opens new paper trades. News bots on mainnet keep trading one coin per article for now.
- Market Making: the cost estimate on the create form now shows only when "Where to quote" is 0, the setting it is measured for. At other settings the form shows fees only and lists markets by volume.

Not financial advice. Past results are not a forecast.
