# v2.18.0 (2026-11-23)

Danh sách tính từ tag `v2.17.1` (2026-11-22, `main` e11ddea) tới #484, cộng PR docs này. Tag `v2.18.0` đặt trên commit của PR docs này.

## Cho người dùng (English, dùng được cho GitHub Release)

- **Signal Research mainnet bots: Settings and Edit.** A Settings button shows the bot's full setup. Edit saves a new version (leverage, position size, max open trades, markets, min level). New signals use it; open trades keep the TP, SL, max hold and leverage they opened with.
- **Safer archive:** a bot with open trades can't be archived until they are closed.
- **Trading Agent** shows Signal Research bots properly: name, configuration, a link to Signal Research, and the Keep / Close all stop dialog.
- **Live funnel:** every new article now drops through the funnel and stops at the step where it was dropped.
- **AI Desk · Needs you** now lists any bot that needs your attention.

Not financial advice. Past results are not a forecast.

## Kỹ thuật

**Bot `news_signal` mainnet**
- Settings chỉ xem: nút Settings trên thanh bot, cấu hình của version đang chạy; API `GET /signal-research/bots` trả thêm `signalVersionId` (#469 phần 1 qua #473).
- Edit thành version mới (#469 phần 2 qua #481, DEC-377; web #484):
  - chỉ 5 field sửa được (Leverage, Position size, Max open trades, Markets, Min level); field khác trả 400 `fieldErrors.{field} = ["locked"]`;
  - áp version **không huỷ lệnh nào** của bot news; state mang nguyên sang version mới; lệnh đang mở giữ TP / SL, max hold, đòn bẩy lúc vào;
  - bot paused áp ngay; bot đã dừng sửa rồi Start chạy config mới;
  - sửa lỗi có từ trước: Stop-Keep rồi Start bỏ mọi tín hiệu `BOT_PAUSED`;
  - Decisions "Applied v{n}".
- **Lỗi tiền thật đã sửa (#471 qua #476, #478, DEC-376):** archive bot news còn lệnh mở làm engine bỏ runner (mất OCO, max hold, Close now).
  - API trả 409 `STATE_CONFLICT {reason: "open_trades"}`.
  - Engine quản lý cả bot `archived` còn lệnh (phòng thủ cho bot đã lỡ archive).
  - Web khoá nút Archive.
- Trang Trading Agent với bot news: tên "Signal Research", Configuration dùng chung component Settings, "Open in Signal Research", `/bots/:id/edit` chuyển hướng, hộp Stop Keep / Close all (#470 qua #475).
- Các luồng dùng chung (#472):
  - "Multi-market" cho bot nhiều market ở mọi danh sách (#479);
  - Strategy Lab mở bot news trong Signal Research (#480);
  - MCP `get_bot` có khối `newsSignal`, `draft_bot_change` từ chối bot news (#482);
  - quy tắc Needs you `bot_needs_attention` cho mọi bot có Needs attention (#483).

**Signal Research**
- Phễu live: mọi bài mới đều rơi theo trace sẵn có; hàng đợi đầy thì tín hiệu giữ chỗ trước; dòng trạng thái không còn nháy về câu idle giữa hai bài (#474 qua #477).
